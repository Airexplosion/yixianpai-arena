## 安全闸

- 只在**不在任何房间 / 对局里**时工作（`isInRoom` 或 `needReconnectToRoom` 为真就拒绝），进场只能从大厅发起。
- manifest 标了 `sandboxOnly`：要在管理器里给配置档打开沙箱模式才能启用。
- 备战界面的操作靠几组钩子离线化（移牌静音、炼化本地模拟、拦下状态请求、「准备」按钮改成开打）。**任何一组没挂全就禁止进场**——宁可不能用，也不把包发出去。游戏更新后如果进不去，看日志里「没挂上」的是哪个方法。
- 不在练习场里时，这些钩子第一句就放行，不读不改任何东西。
- 和探针 `com.yx.arenaprobe` 挂的是同一批方法，**不要同时启用**。

## 用法

1. 大厅里打开模式选择 → **单人模式**，最后一个入口就是「练习场」（克隆自游戏自己的入口，图是原入口的图）。后备：热键 `CTRL+ALT+1`（大厅主界面上原来那个自绘的「练习场」小按钮 0.14.0 起去掉了）。两者都先打开**选英雄界面**——就是游戏自己的单人房间界面（大立绘、「更换角色」抽屉、角色旁的一排仙命、右下「开始」）：

| 在选英雄界面上 | 作用 |
|---|---|
| 更换角色（游戏自己的抽屉） | 选角色、选皮肤，和平时一样。换角色时仙命换成这个角色自带的那几个 |
| 点角色旁的仙命图标 | 弹出游戏自己的**全仙命选择框**换掉这一格（第 1–5 个图标对应炼气…化神）：原生界面，带图标、名字、境界标签，页签 全部 / 角色专属 / 通用 / 各门派，所有仙命不限角色；选「空」清掉这一格；同一个仙命可以放进好几格（注意：游戏里绝大多数仙命只判断「有没有」，重复放不会叠加效果，计数也只有一份）。框的上方有一个「搜名字」输入框（输入仙命名字的一部分回车，列表只剩当前页签里匹配的；清空再回车恢复）；鼠标停在某一格上，选择框右侧会弹游戏自己的仙命说明（搜索和悬停说明这个选择框原本都没有，是补上的）；点图标这条路选完就结束，不会再弹别的窗。用的是游戏里一个现在已经不用、但预制体还在的选择框（`SelectInfoPanel`）；门派秘传编辑器现在用的那个只列「当前角色专属 / 当前门派 / 通用」，所以不用它。原生框打不开时自动退回自绘的全仙命表（同样的筛选 + 名字搜索） |
| 右下「开始」 | 进练习场（会黑屏几秒，那是游戏自己的幕布，然后自动出备战界面） |
| 左上角的小条：正在设置：我方 / 对手 ⇄ | 两方各有一套角色 / 皮肤 / 仙命 / 天衍仙命 |
| 左上角的小条：天衍仙命 | 游戏里没有能把天衍仙命全部列出来的选择框，这里是自绘的分页列表，带名字搜索，点一下选上 / 取消，可多选。选了天衍仙命时，对局轮次会定到所选里「第几轮起生效」最大的那个，保证都生效 |
| 左上角的小条：仙命 / 计数 | 五个仙命槽一览：点名字去全仙命表里选，`×` 清空；「计数」是这个仙命攒的层数 / 次数（比如攒够几次触发一次的那种）在开打时已经有多少 |
| 左上角的小条：返回（或 ESC） | 回模式选择 |

   双方的设置、手牌、场上的牌都跨会话保留。想换角色 / 仙命：回大厅（游戏自己的退出，或 `CTRL+ALT+4`）→ 再点入口 → 改完点「开始」，牌都还在。

   这个界面是借用的：它背后需要一个「模式分页」撑着，借的是原初秘境的那一页（做成了透明、不可点，也不会去同步秘境存档）。游戏的角色抽屉会把「上次用的角色」记进本地设置，关闭时会放回原值；在抽屉里点「确定」会像平时一样把选的皮肤设为该角色的装备皮肤。你正常去打原初秘境时这些钩子不起作用。

2. 控制栏（点「收起 ▲」缩成一个小标签，点「练习场 ▼」展开）：

| 控件 | 作用 |
|---|---|
| 发牌 | 打开游戏自己的图鉴（门派 / 副职 / 机缘 / 秘术筛选都能用）。点一张牌 = 发进正在编辑的一方的手牌；屏幕左侧有一列向上滚动的发牌记录 |
| 特殊牌 + 类别 | 游戏的图鉴不列梦境牌、幻境牌、马牌和各种衍生 / 活动牌。「类别」在 梦境 / 幻境 / 马牌 / 其他 之间切换，「特殊牌」用游戏自己的另一个卡牌面板把这一类显示出来，同样是点牌 = 发牌（牌级照「牌级」设置）。没有境界的牌这个面板显示不了，日志里会记有几张 |
| 搜牌名 | 输入牌名的一部分，回车：所有名字匹配的牌（含梦境 / 幻境 / 衍生牌，不分赛季）用同一个卡牌面板显示出来，点牌 = 发牌。分隔用的圆点和空格不用打（「崩拳封」能搜到「梦·崩拳封」）。只搜到没有境界的牌时（面板显示不了）直接发第一张 |
| 点牌：发牌 / 详情 | 想看卡牌详情时切到「详情」 |
| 牌级 | 发出去的牌可选 1 / 2 / 3 / 4 / 5 级。该牌没有所选等级时拒绝发牌并提示。澄心剑专属入口按境界选择版本 |
| 境界 | 正在编辑的一方的境界（决定基础血量，也影响与境界挂钩的牌）。切换时手牌和场上的牌保留 |
| 先手 | 我 / 对手 |
| 清空手牌 | 只清手牌，场上的不动 |
| 游戏自己的「切换」按钮（备战界面上，旁边的标签写着「练习场 · 我方 / 对手」） | 切到另一方去摆牌、发牌、改数值。这就是复盘模式里那个切换按钮：练习场把它借出来，点击被拦下来改成本地换边（原本要向服务器发切换请求；同一组里的「恢复」「发牌」按钮被藏起来并同样拦下）。对手默认是不出牌的木人；给它摆上牌它就会出牌。按钮被挪到了「修为 / 血量」那一行的右边，标签跟在它后面；位置不合适可以在管理器的配置里调 `layout.switchOffsetX` / `switchOffsetY`（画布单位，往右 / 往上为正）。借不到这个按钮时（游戏更新后钩子挂不上），控制栏上会多出一个「编辑：我方 / 对手 ⇄」顶替 |
| 开打 | 用双方场上摆的牌开打（**点游戏自己的「准备」按钮也一样**）。战斗里有游戏自己的播放 / 暂停、倍速、重播、退出；点「退出」回备战界面 |
| 仙命…（或直接点备战界面上的仙命图标） | **在备战界面里改仙命 / 天衍仙命 / 计数，还能换角色**：同一个小窗，选仙命 / 选角色弹的都是游戏自己的带图标的选择框；改完立刻重新喂一次对局状态（手牌和场上的牌保留）。改的是正在编辑的那一方。在这里换角色，仙命会换成新角色自带的，皮肤回到默认（别的皮肤只有大厅的选英雄界面能保证是你拥有的） |
| 开场暂停：开 / 关 | 开着时每场战斗在第一张牌之前先停下，配合「步进」从头一张一张看 |
| 破限：开 / 关 | 见下面「破限」一节。默认开 |
| 上限：原版 / 解限：9999段 / 解限：99999段 | 游戏自己有两个上限：一场战斗最多 64 个单方回合（双方各 32 回合），一次攻击最多 999 段。「解限」两档都**取消回合上限**，并把攻击段数上限放宽到 9999 / 99999（没做成无限：每一段至少占一帧，99999 段在 60 帧下要将近半小时；打不完随时点游戏自己的退出）。只在练习场的战斗里生效，回到正常对局自动恢复原版数值。配合超大血量的木人，战斗可能永远打不完——这是预期的 |
| 血量 | 正在编辑的一方的总血量，直接输入数字回车（最多 18 位）；填 0 = 跟随境界。备战期炼化等带来的血量上限加成会叠在上面。**超过 20 亿的部分进 64 位血量池**（见「破限」） |
| 体魄 / 体魄上限 | 直接输入。体魄超过上限时上限跟着抬 |

3. **战斗里**：屏幕上边缘有「步进 ▶|」「开场暂停」「伤害统计」三个按钮；伤害统计是屏幕右侧一个带底板的悬浮窗（不挡点击），用第三个按钮开关。一场打完（退出 / 重播）时统计会写进会话日志一行，方便事后对数。
   - **步进**：在暂停时按 = 放行一张牌，下一张牌之前自动再停；在播放时按 = 打完当前这张就停。暂停 / 继续点的是游戏回放面板自己的播放按钮（你直接点那个按钮也一样），不直接改游戏速度。
   - **伤害统计**：双方各一份——总伤害（减防前）与实际掉血、**最大一击（哪张牌打的）**、本回合伤害、上一张牌的伤害、按牌名汇总的前 6 名。全部是 64 位数字、千位分组，不受 21 亿上限限制。伤害记在「当前正在出的那张牌」头上（被它触发的连带效果也算它的）；打自己的不算。每次开打 / 重播清零，打完保留到点退出。
   - 回大厅用游戏自己的退出，或 `CTRL+ALT+4`（战斗演到一半也可以，会先让战斗停下来再走）。
4. 后备热键（按钮不灵时用）：`CTRL+ALT+1` 打开选英雄界面、`CTRL+ALT+2` 开图鉴、`CTRL+ALT+3` 开打、`CTRL+ALT+4` 回大厅。都能在管理器里改键。不用字母键是因为 `CTRL+ALT+字母` 在中文桌面上常被 QQ / 输入法之类的全局热键吃掉（0.1.0 的 `CTRL+ALT+P` 实机按了没反应）。

拖牌上格子、互换、拖回手牌、同名牌叠起来升级、拖进炼化区，都和正常对局一样（炼化牌的效果也会生效）。

## 本地随机数（0.3.0）

战斗里的「随机」不是客户端现算的：每次都是从服务器预先算好的一条数据流里顺序取一个值，而且这个值的含义随调用点不同——百分比判定（0–99）、**牌的 id**（无尽崩绝这类「随机使用 N 张 XX 牌」）、负面状态的类型号、X～Y 的数值。牌池之类的逻辑只在服务器上。练习场没有服务器，所以改成**在取值的那一刻，按「当前是哪张牌在取」现算一个含义正确的值**（`src/Draws/`）：

- 概率判定：0–99；卦象（及星力等同类效果）生效时必中。
- X～Y 的数值（奔雷符、轰雷掣电、御雷卦诀、犀牛望月……以及所有配置里带随机攻击 / 随机防的牌）：区间内随机；卦象生效时取最大。
- 随机减 / 转移自身负面状态（驱邪丹、千斤坠、崩拳•截脉、万魂破军……）：从身上现有的负面状态里随机一种，没有就什么都不发生。
- 施加随机负面状态（挥毫泼墨、疯魔、浮光掠影）：内伤 / 虚弱 / 破绽 / 减攻 / 困缚 / 外伤 里随机一种；梦•白蛇吐信按卡面是内伤 / 虚弱 / 外伤。
- 随机一种效果（落纸云烟、玄冥云烟）：均匀随机。
- 与保留手牌有关的（灵猫乱剑、残云封天剑）：按开打时这一方留在手里的牌算。
- **随机使用 N 张 XX 牌**：牌池按卡面文字重建，是**近似**（真正的牌池只有服务器知道），都在 `src/Draws/CardPools.cs` 里，哪条不对改那一个文件：

## 破限（0.11.0）

游戏的数值全是 32 位整数，到 2,147,483,647 就回绕成负数（伤害变加血、层数变负）。把数值类型整个换成 64 位做不到，练习场做的是三件事：

1. **到顶就停**：第一次「开打」前，把战斗核心（`BattleCharacter`、`CardActionBase`、`BattleExecuter` 等）和场上这些牌的类里的整数加 / 减 / 乘 / 除 / 取负、浮点转整数，改写成饱和版本（SDK 的 `ctx.Hooks.BeginSaturate`，分帧做，控制栏状态行显示「破限准备中 3/11」，好了自动开打；之后只有上了新牌才需要再准备一小下）。战斗里冒出来的牌第一次被打出时现场处理。
2. **真值**：一次运算溢出时，按 64 位算出来的结果被记下来，并沿着这条公式往下带（× 倍率、+ 加成、− 防、÷ 100……）。所以「攻击 × 150 ÷ 100」这种中间溢出、结果没溢出的公式会得到**精确值**；结果本身超过 21 亿的，游戏里显示 2147483647，**伤害统计里显示真实的数**（总伤害、最大一击、每张牌）。
3. **64 位血量池**：血量填到 20 亿以上时，游戏里的血量停在 2,000,000,000，超出的部分记在池子里，每次掉血后自动补回；一刀打出几百亿也按真实伤害从池子里扣，池子盖得住就不死。战斗里伤害统计下面多一行「真实血量 剩余 / 总量」。

限制：上限显示仍是 2147483647（剑意、灵气等层数到顶就停，不会再涨）；真值只跟一条运算链，是启发式的，极端连锁下统计可能偏小；用了血量池的一方，池子没空之前治疗没有意义（游戏里的血量一直是满的），按百分比算血量的效果看到的是 20 亿；改写在本次游戏进程内不可撤销（只发生在练习场里开打之后，重启游戏恢复；正常对局的结果由服务器算，不受影响）。「破限：关」之后不再处理新的牌，已经处理过的保持。

## 和 SDK 的关系（0.13.0）

练习场里原来自己手搓的通用部件已经换成 SDK 的：界面（面板 / 按钮 / 输入框）用 `Yx.ModSdk.Unity.UiKit`，回调自动兜底；钩子一律用 `ctx.Hooks.Group(...)` / `TryPrefix` 登记——「离线保护」那一组不全就禁止进场（`OfflineHooks.Required`），其余各组不全只关掉对应的功能；按钮与热键共用的动作用 `ctx.Guard`；打包用 `yx-patch pack`。想看一个大型 mod 怎么用这些，就读这里的 `src/Game/*Hooks.cs` 和 `src/Ui/`。

## 已知限制

- 换牌不支持（要服务器决定换来什么）：换牌区在练习场里被隐藏了。想要什么牌直接发。
- 少数炼化牌的结果牌由服务器答复给出，本地不会出结果牌。
- 个别仙命 / 牌靠向服务器要状态来刷新备战期的数值，练习场里这些请求被拦下，数值显示可能不更新。
- 皮肤只能在大厅的选英雄界面里选；角色、仙命、天衍仙命、计数在备战界面里也能改。副职、仙命共鸣还不能选。
- 选英雄界面上把某个仙命槽清空后，角色旁那个图标仍显示角色自带的仙命（只是图标，实际已经清掉）。
- 同一个仙命占几个槽：数据里是几份，但战斗界面的仙命图标只显示一个（游戏的图标表拿仙命 id 当键，加第二次会抛异常让整场战斗起不来，0.11.1 起第二次起跳过）。游戏判断「有没有这个仙命」的地方不会因为多选而叠加。
- 选了天衍仙命时会把对局的赛季机制设成「天衍仙命」，备战界面可能因此多出一些相关的界面元素；战斗里的效果读的是我们填的数据。
- `com.yx.skipbattle` 在练习场里会记一行「放弃」——练习场走的是游戏的回放分支，SDK 按设计不在回放里提供跳过。无害。
